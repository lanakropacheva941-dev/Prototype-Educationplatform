# Карта интерфейса «Ясно»

## Сотрудник
- Главная — `/dashboard`
- Профиль — `/profile`
- Учебный маршрут — `/learning-path`
- База знаний — `/knowledge`
- Курсы — `/courses`
- Тестирование — `/tests`
- Мои результаты — `/results`
- Новости — `/news`
- Как пользоваться платформой — `/guide`
- Помощь — `/help`

## Глобальная оболочка
- Поиск — поле в Header; результаты `/search`
- Уведомления — центр уведомлений в Header
- Настройки — из меню профиля `/settings`

## Руководитель
Дополнительный раздел `/team`:
- Обзор
- Сотрудники
- Прогресс обучения
- Результаты тестов
- Просроченное обучение
- Слабые темы
- Контрольные листы
- Запросы на курсы
- Рейтинг команды

## Администратор
Дополнительный раздел `/admin`: пользователи, оргструктура, должности, материалы, База знаний, курсы, маршруты, тесты/банк вопросов, контрольные листы, практические задания, компетенции, назначения, баллы/рейтинг, новости, обращения, уведомления, сертификаты, отчёты, архив, журнал ознакомлений, audit log.
