# Роли и права

## Сотрудник
Проходит назначенное обучение, использует Базу знаний, самостоятельно записывается на разрешённые курсы, проходит тесты, видит собственные результаты, компетенции, баллы и сертификаты.

## Руководитель
Наследует пользовательские возможности сотрудника и дополнительно работает с закреплёнными подразделениями/салонами: видит прогресс подчинённых, назначает разрешённое дополнительное обучение и дедлайны, назначает наставника, подтверждает практику/контрольные листы, согласовывает курсы.

Руководитель не создаёт и не редактирует образовательный контент.

## Администратор
Один административный уровень. Управляет пользователями, справочниками, оргструктурой, материалами, версиями, курсами, маршрутами, тестами, компетенциями, правилами баллов, новостями и системными настройками.

## Правила
- Роль != должность != оргструктура.
- Пользователь может одновременно иметь несколько ролей.
- Должности — настраиваемый справочник.
- Руководитель может иметь несколько подразделений.
- Наставник — отношение между сотрудниками, а не отдельная глобальная роль.
- Права проверяются сервером; скрытие элемента UI не является контролем доступа.
- Поиск не раскрывает даже метаданные недоступных объектов.
