# Архитектура прототипа «Ясно»

## Стек
Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, PostgreSQL, Prisma, Auth.js.

## Слои
- UI: страницы и переиспользуемые компоненты.
- Features: бизнес-модули (маршрут, База знаний, тестирование и т. д.).
- Domain/Data: типы, правила, ORM и серверная логика.
- Infrastructure: БД, авторизация, файлы, будущие интеграции.

## Предлагаемая структура
```
src/
  app/
  components/
  features/
  lib/
  types/
  mock-data/
prisma/
public/
docs/
```

## Ключевые правила
- User, Role, Position и OrgUnit не объединять в одну сущность.
- User ↔ Role — many-to-many.
- Один активный основной LearningPathAssignment на сотрудника.
- Material — единый источник контента; CourseItem и LearningPathStep хранят ссылку на исходную сущность.
- MaterialVersion обязателен.
- «Изучено» и «Ознакомлен» — разные события.
- Исторические подтверждения, результаты тестов и audit log не удалять штатными операциями.
- Авторизацию и RBAC проверять на сервере.
- UI не должен быть источником бизнес-правил.

## Данные прототипа
До подключения PostgreSQL первые экраны могут использовать типизированные mock-data. Mock-модели должны повторять будущие доменные сущности, чтобы замена источника данных не требовала переписывания UI.

## Будущее расширение
Архитектура должна допускать SSO, e-mail/push, HR-интеграции и внешние API без изменения доменной модели.
