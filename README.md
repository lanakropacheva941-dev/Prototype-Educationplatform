# Образовательная платформа «Ясно»

Прототип корпоративной образовательной платформы (LMS + База знаний) для сети оптик «Ясно».

## Цель текущего этапа

Этап 0 — подготовить технический фундамент проекта до разработки пользовательских экранов.

## Планируемый стек

- Next.js + React + TypeScript
- Tailwind CSS
- shadcn/ui
- PostgreSQL
- Prisma
- Auth.js
- React Hook Form + Zod
- TanStack Table
- dnd-kit
- Recharts
- Tiptap Community
- Vitest + Testing Library
- Playwright

## Архитектурные принципы

1. Роль, должность и организационная структура — независимые сущности.
2. Один сотрудник может иметь несколько ролей.
3. У сотрудника одновременно только один основной активный учебный маршрут.
4. Материал Базы знаний хранится один раз; маршруты и курсы ссылаются на него по ID.
5. Версионирование материалов обязательно.
6. Права доступа проверяются на backend.
7. Критические действия должны попадать в audit log.
8. Бизнес-справочники должны настраиваться администратором без изменения кода.
